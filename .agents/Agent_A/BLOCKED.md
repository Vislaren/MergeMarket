# Agent A — Blocked

> This file holds tasks that cannot proceed due to a dependency or issue.
> When a task is blocked, move it here from TODO.md with a clear reason.
> When the block is resolved, move the task back to TODO.md and remove
> the entry from this file.

---

## Blocked Tasks

_No blocked tasks. All tasks are available in TODO.md._

---

## Entry Format

When a task becomes blocked, add an entry using this format:

```markdown
---

### [BLOCKED] A-XX — Task Name
**Blocked since:** Session X
**Reason:** Exact reason this task cannot proceed.
**Waiting for:** What needs to happen before this unblocks.
**Unblocked by:** A-XX or B-XX (the task that must complete first)
**Impact:** Which other tasks are also affected by this block.
```
